# Writing Prototype Issues

## Purpose

Write an assignment for a rough artifact and human feedback that will refine a concept. Require the executing agent
to use the `execute-prototype-issue` skill.

## Scope and Feedback

Describe what people need to react to and what their feedback should clarify. Include the feedback audience when known.
State known scope, effort, fidelity, or iteration limits when they affect the assignment. Do not invent limits or
prescribe product-delivery requirements for a learning artifact.

## Issue Output Format

Read [prototype-format.md](prototype-format.md) only when writing or updating a prototype issue.

## Validation

- The assignment requires the `execute-prototype-issue` skill and identifies what feedback should clarify.
- Scope and known limits support a rough artifact for learning.
- Completion includes collected human feedback, not only an artifact.
- Completion Criteria state only additional requirements specific to this assignment.
- Findings-recording requirements include the artifact link, feedback, and learning in a Markdown document attached to the issue and a short outcome
  in any explicit entry in its linked project description.
