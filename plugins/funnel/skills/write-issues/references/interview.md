# Writing Interview Issues

## Purpose

Write an assignment to refine a concept, design, or idea through dialogue. Require the executing agent to use the
`execute-interview-issue` skill, which uses the generic `interview` skill.

## Concept and Scope

Describe the concept and its known boundaries. Include relevant settled decisions, constraints, and open questions
from the available context. Leave unresolved decisions open; do not write a predetermined conclusion or a full
interview script into the assignment.

## Issue Output Format

Read [interview-format.md](interview-format.md) only when writing or updating an interview issue.

## Validation

- The assignment requires the `execute-interview-issue` skill and identifies the concept and known boundaries.
- Settled decisions and open questions are distinguishable, with no predetermined conclusion.
- Completion Criteria state only additional requirements specific to this assignment.
- Findings-recording requirements include the human-confirmed synthesis in a Markdown document attached to the issue and a short outcome in any
  explicit entry in its linked project description.
